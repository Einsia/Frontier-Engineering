# NCAAInsertion - 非规范氨基酸插入设计

## 概述

在固定蛋白质骨架的指定位置插入 **非规范氨基酸 TRF（N1-甲酰基色氨酸）**，并重新设计周围残基来稳定整个结构。本任务覆盖 **3 个不同的蛋白质骨架**，全面评估 agent 处理非规范氨基酸的能力。

本任务对应 Agent Rosetta 论文（arXiv:2603.15952, ICML 2026）的 **Case B**。

## 生物学背景

### 什么是非规范氨基酸（NCAA）？

蛋白质通常由 20 种标准氨基酸组成。但自然界中还存在数百种"非标准"的氨基酸，它们能提供标准氨基酸不具备的化学功能：

| 功能 | 示例 | 应用场景 |
|:----|:-----|:---------|
| **荧光探针** | 丹酰基、对氰基苯丙氨酸 | 追踪蛋白质在细胞内的位置和运动 |
| **光交联** | 对苯甲酰基苯丙氨酸 | 捕捉蛋白质之间的瞬时相互作用 |
| **新催化活性** | 含硒半胱氨酸、吡咯赖氨酸 | 设计具有全新反应机制的酶 |
| **改善药代** | 氟代氨基酸 | 提高多肽药物的稳定性和半衰期 |

### 为什么这个任务重要？

大多数基于机器学习的蛋白质设计模型（如 ProteinMPNN）**只接受 20 种标准氨基酸**，无法处理 NCAA。Rosetta 基于物理方程计算能量——它不靠"见过什么"来设计，而是靠"算能量"来评分——因此可以建模任意非标准化学结构。

**这是 Rosetta 相对于 ML 方法的独特优势**，也是这个 benchmark 要评估的核心能力。

### TRF（N1-甲酰基色氨酸）是什么？

TRF 是色氨酸（Tryptophan, Trp）的衍生物，在吲哚环的 N1 位置上多了 **一个甲酰基（-CHO）**。这个微小改变使得 TRF 具有与普通色氨酸不同的化学性质：
- 甲酰基可以作为氢键受体，与周围残基形成额外相互作用
- 改变了吲哚环的电子分布，影响 π-π 堆积
- 在蛋白质核心中引入额外的极性基团，挑战设计能力

## 测试蛋白质

本任务包含 **3 个不同的蛋白质骨架**，涵盖不同的折叠类型和大小：

| 蛋白 | PDB ID | 长度 | 折叠类型 | TRF 位置 | 设计位置数 |
|:----|:------:|:----:|:---------|:--------:|:----------:|
| Ubiquitin（泛素） | 1ubq | 76 | α/β 混合 | 4 | 8 |
| Protein G B1 domain | 1bdd | 56 | α/β 混合 | 3 | 8 |
| Engrailed homeodomain | 1enh | 54 | 全 α 螺旋 | 5 | 8 |

**评分方式**：每个蛋白单独评分后求和，总能量越低越好。所有蛋白的 TRF 都必须正确插入，才算有效设计。

## 输入

candidate 脚本（`scripts/init.py`）接收：

- `--prepared-input`：准备好的 PDB 文件路径（TRF 已插入，参数已加载）
- `--solution-output`：设计结果的 PDB 输出路径

## 输出

candidate 必须输出一个 PDB 文件，包含：
1. 原始的骨架坐标（**不变**）
2. **在指定位置保留 TRF（N1-甲酰基色氨酸）**
3. 在周围设计位置优化后的氨基酸侧链
4. 非 TRF 位置只能使用 20 种标准氨基酸

## 评分方式

评估器使用 PyRosetta 的 `ref2015` 能量函数（加载 TRF 额外残基参数）：

| 指标 | 说明 |
|:----|:------|
| `trf_present` | TRF 是否正确插入到目标位置 |
| `total_energy` | Rosetta ref2015 总能量（越低越好） |
| `improvement` | native_energy - total_energy（正值表示改进） |
| `combined_score` | improvement / \|native_energy\|（归一化改进）|

仅当 TRF 在正确位置时，`combined_score` 才有效；否则为 `-1e18`。

## 约束

1. 只能修改 `scripts/init.py`
2. 不能修改骨架坐标
3. TRF 必须在指定位置存在
4. 非 TRF 位置只能使用标准 20 种氨基酸
5. 输出必须是有效的 PDB 文件
6. 必须处理所有 3 个测试蛋白（由评估器自动遍历）

## Agent 可优化的方向

1. **多轮迭代设计**：反复 repack 以寻找更优的 rotamer 组合
2. **TRF rotamer 搜索**：尝试 TRF 的不同侧链构象，选择能量最低的
3. **蒙特卡洛模拟退火**：以一定概率接受能量升高的改动以跳出局部最优
4. **骨架微柔**：在 TRF 附近允许小幅度骨架调整（需注意约束）
5. **位点协同设计**：一次改变多个位置，而非逐个优化
