## Overview

Manufacturing scheduling problems involve allocating limited resources (machines, workers) to production tasks (operations) over time. The objective is typically to minimize total production time (makespan), reduce costs, or improve resource utilization.

These problems are NP-hard and represent real-world challenges faced by manufacturing engineers daily. Improving scheduling quality has direct economic impact:
- Higher machine utilization
- Shorter order delivery times
- Lower production costs
- Better worker allocation
