# 电子设计自动化

电子设计自动化将行为级或结构级电路描述转化为满足功能正确性、面积、
时序、功耗和物理约束的实现。本领域任务同时提供可优化的工程决策与可由
机器独立验证的目标。

## 任务

| 任务 | 描述 | 运行环境 |
|---|---|---|
| [CertifiedAIGResynthesis](CertifiedAIGResynthesis/) | 带证明证书的 DAG 感知布尔重综合：精确验证小割集等价性，并按面积与深度评分 | Python 3 + C++17；仅 CPU |

`IntegrationPhysicalDesignOptimization` 仅保留为历史占位，不是可执行基准。
