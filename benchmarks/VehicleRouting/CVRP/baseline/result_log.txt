Notes
-----
* 24 instances = 12 public (data/instances/, VRP-*) + 12 held-out
  (data/instances_heldout/, VHO-*). Held-out instances are scored at
  evaluation time only and never shown to agents.
* Reference distances are precomputed by verification/ref_solver.py
  (deterministic, seeds (123, 2024, 7)) into data/reference.json.
* The candidate subprocess runs without FRONTIER_EVAL_UNIFIED_* and
  reference-distance env vars, and the evaluator statically rejects
  candidates that reference verification code, reference.json, absolute
  paths, or per-instance hardcoded routes (see check_candidate).

Multi-seed statistics (verification/multiseed_stat.py)
-------------------------------------------------------
The released evaluation set is fixed, so the (deterministic) baseline scores
identically on it. To report a multi-seed distribution, this script derives
fresh instance sets from three seeds (generate_instances generate_instance
seed=...) and computes each set's reference distances on the fly.
