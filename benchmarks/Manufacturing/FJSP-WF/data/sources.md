# Data Sources for FJSP-WF Benchmark

## Official Benchmark Instances

This benchmark uses the official instance set from the **GECCO FJSSP-WU Competition** (Flexible Job Shop Scheduling Problems with Worker Flexibility under Uncertainty).

- **Competition Website:** https://jrc-rodec.github.io/FJSSP-W-Competition/
- **Source Repository:** https://github.com/jrc-rodec/FJSSP-W-Competition
- **License:** Apache-2.0
- **Instances:** 30 FJSSP-W instances (with native worker flexibility data)

### Worker Flexibility Extension

The worker flexibility data was generated by the competition organizers using a published methodology (`util/rewrite_benchmarks.py` in the competition repository):

1. **Worker count**: `worker_amount = int(num_machines * 1.5)`
2. **Worker speed factor**: `random.uniform(0.9, 1.1) × original_processing_time`
3. **Worker eligibility**: Each machine randomly assigned `randint(1, worker_amount)` workers

All instances in `data/instances/official/` are the original `.fjs` files from the competition repository, included unchanged.
