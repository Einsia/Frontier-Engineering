# MarketMaking（做市工程）

本领域包含轻量、确定性且完全离线的做市控制任务。每个合成公司都有一个流动性较高的主市场
品种，以及一个流动性较低但共享潜在公允价值的 `DUAL` 品种。

任务不连接真实交易所，也不使用真实行情；它保留价差收益、不利选择、库存控制、跨市场价格偏离、
流动性变化和风险约束等核心工程权衡。

## 任务

- `InventoryAwareQuoting`：在流动性、波动率、订单流和 basis 不断变化时，为 DUAL 市场报价并
  控制库存。

任务使用三组合成品种：`NVDA/NVDA_DUAL`、`JPM/JPM_DUAL` 和
`AMZN/AMZN_DUAL`。这些名称只用于场景标识。
