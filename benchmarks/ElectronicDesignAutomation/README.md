# Electronic Design Automation

Electronic design automation turns behavioral and structural circuit descriptions
into implementations that satisfy correctness, area, timing, power, and physical
constraints. The tasks here expose optimization decisions together with
machine-checkable engineering objectives.

## Tasks

| Task | Description | Runtime |
|---|---|---|
| [CertifiedAIGResynthesis](CertifiedAIGResynthesis/) | Proof-carrying, DAG-aware Boolean resynthesis with exact small-cut equivalence checking and area/depth scoring | Python 3 + C++17; CPU only |

`IntegrationPhysicalDesignOptimization` is retained as a historical placeholder
and is not an executable benchmark.
